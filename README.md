\# SOC Home Lab – Security Monitoring \& Incident Investigation\## Project OverviewThis project demonstrates a hands-on Security Operations Center (SOC) home lab designed to monitor Windows endpoint activity, detect security alerts, and investigate potentially suspicious processes.The lab was built using VirtualBox, Wazuh SIEM, Windows 11, and Microsoft Sysmon.The goal is to develop practical skills in security monitoring, log analysis, alert triage, and incident documentation.\## Lab Environment| Component | Purpose ||---|---|| VirtualBox | Hosts the virtual lab environment || Windows 11 | Monitored endpoint || Wazuh SIEM | Collects and analyzes security events || Microsoft Sysmon | Provides detailed Windows process activity logs || PowerShell | Supports endpoint investigation |\## Skills Demonstrated\- SIEM monitoring and alert investigation\- Windows event log analysis\- Sysmon process creation analysis\- Parent-child process investigation\- Digital signature verification\- Security incident documentation\## Investigation Cases\### Case 001 – Suspicious Process InvestigationInvestigated a Wazuh Level 12 alert involving the Windows utility `sdbinst.exe`.\*\*Finding:\*\* Likely Benign — Further Validation Recommended\[View Case 001 Investigation](Case-001/README.md)\## Project StatusLab environment configured and operational.
